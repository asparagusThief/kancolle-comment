# kcwiki 角色资料核查

## 适用与工具

在创作涉及舰娘性格、喜好、关系或口吻的文案前核查。只固定旗舰、正文不涉及角色描写时无需强行关联设定。

核查的用途是确认身份、设定与表达是否冲突。先理解玩家想表达的情境，再查所需资料；普通角色相关签名以玩家感想和相处场景为主要构思方向。只有用户要求角色说话、原句引用或台词梗时，才以其语言习惯或台词结构作为创作骨架。

使用宿主智能体已有的网页搜索与页面读取工具。该 Skill 提供检索流程，不自带联网服务；本地 `corpus.py` 只检索历史选拔记录，不会联网查询角色，也不检测 OOC。

kcwiki 的舰娘百科可从 [中文站](https://zh.kcwiki.cn/) 检索。角色主页面通常包含日中名称、改造阶段、语音、时报和角色介绍；页面结构可能变化，应沿实际目录与链接读取，不假定每位角色都有独立的“/语音”子页面。

## 找到正确角色

将用户提供的中文名、日文名或昵称对应到《舰队 Collection》的角色，确认原名和指定的改造阶段。使用有歧义的昵称且不能确定对象时，先澄清，不拿同名角色代替。

优先搜索：

```text
site:zh.kcwiki.cn <角色名> 语音
site:zh.kcwiki.cn <角色名> <主题或语音场合>
```

打开匹配页面阅读正文，确认舰种、日文名等身份信息，防止混用其他舰船拟人作品中的同名角色。用户未指定改造阶段时，可用跨阶段共同且已核实的表达；确需某阶段专有台词时注明，必要时确认。

## 读取与取证

围绕本次主题阅读相关资料，不必摘录整页：

1. **本次需要的角色事实**：确认名字、改造阶段，以及文案实际使用的喜好、关系或背景；不为了凑角色梗摘取整份口癖清单。
2. **相关语音与场合**：用母港、时报、婚后或限定语音核查具体主张，保留其形态与条件。通用的同行愿望不需要寻找一条完全相同的台词来证明发生过。
3. **说话方式**：写角色对白时才具体核对自称、称呼、礼貌程度和句尾；玩家自己的感想保持玩家口吻。

保留少量与创作直接有关的证据，记下日语短摘录、场合、改造阶段、页面链接和访问日期。较长台词概述即可，引用遵守宿主的摘录限制。页面同一时段的多句语音应结合语境理解。

注意以下页面特性：

- 改造形态可能只列新增或变化的台词；没有重复列出不等于不再使用，需看页面说明或对应形态资料。
- 限定语音可能动态加载。只看到“加载中”不能认定角色没有相关台词，或声称已完成限定语音核查。可使用网页工具读取完整内容，或搜索对应语音资料页；仍不可读则标明缺项。
- 简繁转换、页面重定向和日文转写可能不同。称呼、语尾或引用有疑问时，以可核实的日语资料为准，不从中文译文反推日语原句。

## 区分证据层次

| 资料 | 如何使用 |
| --- | --- |
| 游戏日语台词、可追溯的官方材料 | 作为具体用词、行为或设定的依据；台词仍有使用条件 |
| kcwiki 对游戏内容的解释 | 作为参考，保留其推断性质；重要主张尽量追溯原依据 |
| CP、同人梗、编辑玩笑、讨论与删线吐槽 | 仅在用户需要这类创作时采用，注明属于同人语境 |
| 动画、街机或其他官方衍生作品 | 明确作品范围，不自动移植为网页版游戏的设定 |
| 历史舰船资料 | 可支持舰历梗，不能直接推出舰娘的性格或个人喜好 |

kcwiki 是社区百科，“角色设定”栏目也可能混合不同层次的内容。避免把无来源标签、某次特殊反应或译者选词当作固定设定。

## 应用于文案

区分玩家表达、角色口吻和原创互动场景。一起出门、等待归来、准备点心等普通场景可从玩家意图原创，不必改写某条母港或时报台词。原文资料主要约束事实、明显冲突和确需使用的说话方式。

检索历史案例时，可同时看玩家感想和相处场景，不把同一角色的名台词样式当成唯一范本。少量自然联想可以保留；用户没有要求玩梗时，候选主要依靠场景和文字本身成立。

自称及称呼应用在正确的说话者身上；婚后、特定对象或特殊场合的语气不默认泛化。名字也无需出现在每一句正文里，固定旗舰或另一栏可以承担角色关联。

对作为既有事实宣称的癖好、关系或性格反应检查依据；普通的邀约、感想和同行愿望可作原创，不要求官方曾发生过同一场景。亲密程度依用户选择和本次创作前提处理，不能把原创关系宣称为官方关系。角色对白保持有依据的口吻；查过资料也不能保证“绝不 OOC”。原创性质可在整批说明，无需逐句重复标注，不能把新文案标成游戏原句。

实际采用设定和语气资料时，附精简依据与访问过的 kcwiki 链接，多个候选可共用核查说明。玩家自己的感想与原创场景无需逐条配一段台词依据。性格推断与原创内容保持可辨，资料说明不掩盖文案本身。

## 资料缺失时

优先使用 kcwiki 可读内容。若存在转写分歧或相关段落不可读，可沿角色页实际提供的日文攻略 Wiki 链接核对语音，并说明补充来源，仍将原始音频或官方材料视为更直接的依据。

没有联网工具、无法确认角色或关键资料缺失时，明确核查范围。可以先提供不包含具体性格断言的玩家感想，也可请用户提供相关台词；依赖未确认设定的创作保持待核实，不声称查过网页。
